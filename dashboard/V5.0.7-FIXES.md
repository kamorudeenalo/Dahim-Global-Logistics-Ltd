# Dahim Dashboard v5.0.7

- WordPress-style Insights list: All Posts, Published, Drafts, Bin.
- Added post title/category/author/date columns, bulk actions, category filter and search.
- Added restore and permanent-delete handling for Bin.
- New/Edit Post editor now uses a sticky toolbar and sticky publish bar.
- Fixed Paragraph/Heading selector by preserving the editor selection before toolbar controls take focus.
- New posts default Publish Date to the current local date/time.
- New post slug is automatically generated from the title until the slug is manually edited.
- Inline images can be clicked, resized by percentage, aligned left/center/right, or removed.
- New Post action uses Publish Post rather than Save Draft; status still controls draft/pending/published behavior.
- Shipment creator retains its WordPress post Title field.
- Production enhancement assets are versioned to avoid stale PWA/browser cache.
