# Dahim Dashboard v5.1.0 — Posts 2.0

This release consolidates the Posts workflow in the React source and ships a production compatibility bridge for the prebuilt deployment because this package was prepared without a fresh npm dependency install.

## Posts improvements
- Server-side pagination and search/filter parameters in the React Posts implementation.
- Global tab counts from WordPress REST totals.
- Published, Pending, Drafts, Scheduled and Bin views.
- Category, author and date filters.
- Bulk actions with success/failure reporting.
- WordPress site timezone-aware new-post date and scheduling conversion.
- Automatic new-post slug generation; existing slugs are preserved.
- Sticky editor action bar and rich-text toolbar.
- Working heading selector with selection preservation and current-block detection.
- Media Library insertion and image upload.
- Inline image width, alt text, alignment and removal controls.
- Featured image preview, replacement, Media Library selection and removal confirmation.
- Categories/tags as checkbox taxonomies with inline creation.
- Existing publishing/discussion settings loaded for editing.
- Password-protected post editing does not expose an existing password; a new password replaces it.
