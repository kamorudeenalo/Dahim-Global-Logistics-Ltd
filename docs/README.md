# Dahim Standalone Platform

## Stage 0 — Project Foundation

This repository currently contains the existing Dahim WordPress/theme/plugin/dashboard implementation. Stage 0 establishes the controlled transition from that architecture to a standalone Dahim platform.

## Project direction

The target system will no longer depend on WordPress for its website, dashboard, authentication, content management, SEO, media management, shipments, inquiries, or application API.

The target platform is intended to provide:

- Public Dahim website
- Private administrative dashboard
- Application authentication and roles
- Simplified Insights publishing
- Native SEO analysis and metadata
- Media library
- Shipment management and tracking
- Inquiry management
- Dashboard analytics
- Centralized settings and branding

## Stage 0 rule

No production implementation of the new platform begins until the requirements, architecture, migration plan, and acceptance criteria in `docs/` are reviewed.

## Repository rule

Every meaningful change must be traceable to a Git commit and, where appropriate, a GitHub Issue or Pull Request. Documentation must be updated when implementation changes the documented behaviour or architecture.
